# Petit Protocol

An offline-capable training companion for Dr Jan Petit's bowel-perforation teaching with clinical officers in Malawi.

This is a **training and wet-lab aid only**. It is not for use in live patient care.

Open the prototype: [Petit Protocol](https://robertsacranietech-ctrl.github.io/petit-protocol/)

You can also open `index.html` directly in a browser with no internet connection.
